# Döviz & Altın Takip Uygulaması

Bu proje, HTML, CSS ve JavaScript kullanılarak geliştirilmiş mobil uyumlu bir web uygulamasıdır.  
Uygulama, döviz (USD, EUR, GBP) ve altın (Gram ve Ons) fiyatlarını modern bir arayüz ile göstermeyi amaçlamaktadır.

Bu sürüm taslak aşamasıdır.  
Sonraki adımda gerçek zamanlı API üzerinden fiyat verileri alınacaktır.
